# Flexible Polygon Editor

QGIS上でライン・ポリゴンを効率よく編集するためのプラグインです。頂点や辺の移動、複数点による地物分割、ラインからのポリゴン再生成を、ツールバーから実行できます。

## 必要環境

- QGIS 3.22以降
- 編集対象のベクターレイヤー

## 主な機能

### 頂点移動

- 編集モード中のライン／ポリゴンの頂点を移動
- 辺の上をクリックして頂点を追加し、そのまま移動
- スナップ設定に従って移動
- 関連する地物の頂点をまとめて移動するトポロジカル編集

### 地物分割（複数点／曲線）

- 複数のクリックで分割ラインを作成
- 直線モードと曲線モードを切り替え
- ポリゴンまたはラインを分割
- プロジェクトCRSとレイヤーCRSが異なる場合も座標を変換
- 無効なジオメトリを修復してから分割を再試行

### Polygonize

- 複数のラインレイヤーを選択してポリゴン化
- 端点チェックで未接続の端点を診断
- 孤立端点のスナップ、または各セグメントの強制閉合
- 既存ポリゴンとの重なり面積を使った属性引き継ぎ
- 既存のポリゴンレイヤーを更新、または新しいメモリレイヤーを作成

## インストール

### ZIPファイルからインストール

1. GitHubの **Code > Download ZIP** からリポジトリをダウンロードします。
2. ZIP内のプラグインフォルダー名を `FlexiblePolygonEditor` にします。
3. QGISで **プラグイン > プラグインの管理とインストール** を開きます。
4. **ZIPからインストール** を選択し、ダウンロードしたZIPを指定します。
5. プラグインを有効化します。

### 手動インストール

リポジトリを、QGISのユーザープラグインディレクトリに `FlexiblePolygonEditor` フォルダーとして配置します。QGISの **設定 > ユーザープロファイル > プロファイルフォルダーを開く** からプロファイルフォルダーを確認できます。

一般的な配置先は次のとおりです。

```text
<プロファイルフォルダー>/python/plugins/FlexiblePolygonEditor/
```

配置後、QGISを再起動してプラグインを有効化してください。

## 使い方

### 頂点を移動する

1. 編集対象のラインまたはポリゴンレイヤーを編集モードにします。
2. **頂点移動** ツールを選択します。
3. 頂点または辺をクリックします。
4. 移動先をクリックして確定します。
5. 右クリックまたは `Esc` でキャンセルできます。

### 地物を分割する

1. 分割対象レイヤーをアクティブにして編集モードにします。
2. **地物分割（複数点/曲線）** ツールを選択します。
3. キャンバス上をクリックして分割ラインの頂点を追加します。
4. ダブルクリックまたは `Enter` で分割を実行します。
5. 右クリックまたは `Backspace` で直前の頂点を取り消します。
6. `Esc` で操作をキャンセルします。
7. `C` で直線モードと曲線モードを切り替えます。

### ラインからポリゴンを生成する

1. **Polygonize** をクリックします。
2. ポリゴン化に使用するラインレイヤーを選択します。
3. 必要に応じて **端点チェック** で未閉合箇所を確認します。
4. 必要に応じて自動閉合を実行します。自動閉合は元のラインレイヤーを直接編集するため、必要に応じて編集のUndoを利用してください。
5. 属性の引き継ぎ元ポリゴンレイヤーとIDフィールドを選択します。
6. 更新先ポリゴンレイヤーを選択するか、新規メモリレイヤーを選択します。
7. **Polygonize 実行** をクリックします。

## 注意事項

- 頂点移動と地物分割には、編集モードが有効なライン／ポリゴンレイヤーが必要です。
- 地物分割はアクティブレイヤーを対象にします。
- Polygonizeを安定して実行するには、ラインの端点が正確に接続され、閉じたネットワークになっている必要があります。
- 自動閉合や既存ポリゴンレイヤーの更新は、QGISの編集バッファーに変更を加えます。実行前にプロジェクトを保存することを推奨します。
- Polygonizeで曲線ジオメトリを使用する場合、処理時にラインジオメトリへ変換されます。

## 開発

このプラグインはQGISのPythonプラグインとして動作します。主なファイルは次のとおりです。

- `flexible_polygon_editor.py`: プラグインの初期化とツールバー登録
- `map_tool.py`: 頂点移動・地物分割ツール
- `polygonize_tool.py`: Polygonize、端点診断、自動閉合、属性引き継ぎ
- `metadata.txt`: QGISプラグインメタデータ
